# VisualFiles 核心体验升级计划与实施记录

日期：2026-11-06。基线：v0.7.12。状态：三轮代码与隔离验收已完成，真实宿主与用户研究待验收。依据：[功能设计与 UI 交互评审](PRODUCT_UI_REVIEW.md)。

覆盖全部 11 项问题，按三轮独立验证、构建和打包。核心流程为“找文件 → 理解内容与改动 → 添加引用”。产品当前行为以 [PLAN.md](../PLAN.md) 为准。

## 第一轮：搜索与 Markdown

范围：R01、R02、R03、R09。

- “仅改动”在服务端截断前筛选；最多展示 500 项，第 501 个有效命中才标为截断。查询条件及改动集合变化重新搜索，过期响应不覆盖新结果。
- 区分读取、失败、无结果和截断，搜索和树空态均提供取消过滤入口。
- 全文搜索打开 Markdown 源码，定位当前磁盘命中行，不将磁盘行号应用到 HEAD。
- 有 Diff 的 Markdown 默认源码差异，通过共享模式切换预览对照；新增文件保持当前全文。
- 标题生成稳定、可重复的中文锚点，保留跨文件链接片段，限定对应版本预览的定位范围。
- 搜索 MCP 增加可选 `onlyChanged`，默认 false，响应结构不变；文件打开入口携带行号、章节与版本定位信息。

验证记录：隔离断言通过 500/501 项、截断前筛选、大小写与忽略规则、重复标题及编码片段、引用草稿 send:false、移动冲突和自身后代保护、符号链接边界。隔离浏览器已确认 Markdown 默认源码差异、命中行高亮、重复标题仅滚动对应侧，以及过滤空态和解除入口。检查、构建及打包通过。

## 第二轮：阅读、版本与引用界面

范围：R04、R05、R08、R10、R11。

- 同文件共用身份栏、添加引用和关闭入口，复制路径放入次级菜单。
- 内容区不足 640px 时用 HEAD／当前磁盘切换，达到 640px 时并排；窄屏保留差异标记。窗口变化不改变活动版本、选区、阅读位置或用户保存的树宽。
- 不能同时容纳树和 320px 阅读区时临时收起树，原按钮切换树与阅读，选择文件后返回内容。
- 引用菜单实时说明文件、选区、HEAD 及目标草稿；已知宿主不支持时提前解释并提供复制路径。保留执行校验及不自动发送。
- 项目入口说明只切换浏览目录；定义历史明确其范围。收拢重复状态，Git 标识补文字解释，统一主题及焦点样式。
- 保持旧浏览记录兼容，不增加必填持久化字段。

验证记录：隔离浏览器通过 420/800/1280px 面板、639/640px 内容区边界、单一关闭入口、窄屏差异标记、版本切换和调整宽度后的选区保持；磁盘文件及选区加入当前/新对话的草稿元数据均为 send:false。浅深主题截图已检查。补充回归通过实际 420px 视口、长路径换行、树/阅读互斥显示、窗口从宽到窄的切换、分栏键盘调整和拖拽后的宽度保存及恢复。窄屏保留编辑器实例和几何尺寸，避免切换树时丢失选区或阅读状态。检查、构建及打包通过。

## 第三轮：操作反馈与恢复

范围：R06、R07。

- 连接、同步、文件读取和搜索错误分别恢复；操作弹窗仅显示本次错误，保留输入。
- 剪贴板与引用失败提供对应说明及用户主动操作；写入成功后的刷新失败单独报告，不自动重放写操作。
- 拖拽显示有效落点、目标路径与过程状态，成功后定位新位置；过滤明显无效目标，后端数据保护继续生效。
- 目标目录选择区分加载、空目录与失败，提供读取重试；保留键盘菜单移动入口。

验证记录：隔离浏览器通过文件读取失败与重试、搜索失败与重试、重名冲突保留输入、新弹窗清除旧错误、目标目录慢请求/空目录/读取失败、剪贴板失败与主动重试。真实浏览器拖拽到目录触发正确移动请求，落到文件等无效目标不提交写入；目标提示使用浮层避免推移落点。

移动成功后注入同步失败，弹窗正常关闭，重试只执行读取，写入次数保持不变。关闭文件能取消慢请求的后续界面更新。绑定失效后只有重新连接入口，跨越一个轮询周期的请求数不增加，重新连接成功后恢复读取。所有宿主调用由隔离桥接桩记录，没有向真实聊天添加或发送内容。

临时文件系统断言通过成功移动、重名保护、自身/后代拒绝、根目标判断、符号链接边界、内容及 HEAD 版本变化和草稿能力判断。检查、构建及打包通过。

- 行为测试仅用仓库外临时项目，完成后清理页面、脚本及产物；不增加仓库测试框架或遥测。
