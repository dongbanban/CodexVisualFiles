# VisualFiles：确认的实施范围（0.7）

## 产品行为

- 独立面板，通过聊天调用或对话内入口打开，不注册全局侧栏入口或全局快捷操作。只能选择本机已登记的 Codex 项目及其源目录，不再提供系统目录选择；未登记目录由后端拒绝。已登记项目的受管理 worktree 保留实际工作目录绑定。
- 文件树支持目录折叠、图标、定位和按需读取。隐藏目录正常展示，Git 忽略项目显示并置灰。
- 文件内容只读：全文、语法高亮、行号、文件内搜索、Markdown 和图片预览。没有文件编辑或保存功能。
- 顶栏项目名与路径同行，移除独立路径行和左侧产品名；树内操作按钮距滚动条 8px。
- 左右分隔线支持连续拖拽调整宽度；文件树最小 240px、内容区最小 320px，窗口不足时横向滚动。拖拽结束后保存文件树宽度，隐藏后重新显示或重新打开时恢复，不设固定的 600px 上限。
- 提供文件内跳转历史，以及 JS/TS（含 JSX/TSX 等扩展）的同文件定义跳转；HEAD 与磁盘分别解析并校验内容版本。搜索结果点击后自动定位到匹配行，不提供手动按行/列号跳转。其他语言可只读显示，当前配置 143 个高亮语言/格式模式。
- Git 对比以 HEAD 为基准，另一侧为当前磁盘内容，包含已暂存和未暂存的改动；显示新增、修改、删除及目录内改动，可筛选仅改动。
- 所有文件名、目录名及路径匹配区分大小写，支持仅大小写变更的重命名；文件名和全文搜索区分大小写，默认跳过忽略项目，可开启包含忽略文件。
- 文件变化自动更新内容和状态，保留当前布局和阅读位置；再次点击按查看位规则分配。
- 文件和目录支持新建、重命名、移动、复制、剪切、粘贴、删除；目录操作递归全部子目录和文件。复制同名生成副本，剪切同名报错保留源文件。移动支持拖拽和菜单选目录；菜单“删除”进入系统废纸篓。
- 文件右键及行尾操作菜单提供“Codex 原生查看”，先复用后端路径校验，再通过宿主 `openai/files/open` 打开当前磁盘文件。目录不提供此项；文件不存在、路径无效、客户端不支持或宿主调用失败时显示错误，不回退到系统外部应用。
- 标题栏提供绝对/相对路径复制选项。“添加到对话”通过 MCP 消息草稿接口将文件、目录或选中代码引用加入当前或新对话，不填写问题、不自动发送。文件和目录的右键菜单均提供“添加到当前对话”和“创建新对话”。HEAD 代码引用保留原版本内容和行号。拖拽仅用于在文件树内部移动文件和目录。
- 展开状态、当前文件、Diff 布局、阅读位置和过滤设置按实际工作目录独立保存，关闭或重启后手动打开可恢复。

## 文件内容面板

默认单面板：每次选择普通文件或新增文件直接展示当前磁盘内容，替换此前文件。HEAD 中已有的文件存在 Diff 时自动左右对照，左 HEAD、右磁盘；切换其他文件按新文件是否有 Diff 决定布局。关闭文件清空整个内容区。

| 点击过程           | 展示                         |
| ------------------ | ---------------------------- |
| A 普通 → B 普通    | 单面板 B                     |
| A 普通 → B 有 Diff | 左 B HEAD、右 B 当前         |
| B 有 Diff → A 普通 | 单面板 A                     |
| A/B 均有 Diff      | 最后点击文件的 HEAD/当前对照 |

新增文件（HEAD 中不存在，含未跟踪与已暂存新增）只展示当前全文，不提供 Diff 入口；旧的新增文件双栏记录在读取后恢复为当前版本单栏，保留阅读位置。删除文件的磁盘侧显示“文件不存在”。旧双文件浏览记录恢复为原活动文件的单面板，同一文件的有效 Diff 保持双栏。

右上角保留手动刷新图标，手动及自动同步时都旋转，手动刷新另显示“刷新中…”状态，完成后提示。普通单面板不展示版本说明。自动同步文案为“自动同步 · 每 2 秒”，定时刷新已展开目录、Git 状态和当前文件，保持布局及阅读位置。所有消息提示 3 秒后消失。树头部图标有悬停提示，并使用纵向折叠图标。UI 统一采用 shadcn Base Nova 组件及 Tailwind CSS 工具类，替换原有手写组件样式。

## 打开方式与验收边界

文件树仅由用户手动打开；面板打开后每 2 秒同步当前分支及文件状态。

对话内入口只把宿主目录元数据/唯一 MCP root 用于提示当前目录，不自动替用户打开。只能通过已登记项目列表选择项目及其源目录；Agent 工具显式提供的工作目录也必须是已登记项目源目录或其受管理工作树。列表不可用时提供刷新重试，无任意目录回退。

本机项目列表使用 Codex app-server 实验性 project/list 读取；项目选择仅控制 VisualFiles 的文件树浏览。真实客户端的入口位置和创建新对话需要单独验收。

当前公开 SDK 未提供将本地路径加入原生 `@` 文件附件或向聊天框发起原生文件拖拽的接口。已移除聊天框拖拽导出代码；菜单添加使用官方插件上下文草稿接口，不承诺原生文件附件的处理方式。

仓库仅保留生产代码、文档及构建检查，行为验收在仓库外临时运行并清理脚本与产物。人工维护文件不超过 500 行，实施规范见 `AGENTS.md`。根目录及显示名称统一为 `VisualFiles`，机器标识统一为 `visualfiles`。

4. 打包、安装、重启恢复及完整行为验收。
